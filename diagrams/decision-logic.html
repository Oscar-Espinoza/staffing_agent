Staffing Risk Agent · Decision Logic

When the agent refuses to answer

One Kantata allocation row, traced from ingestion to verdict — where the pipeline reads a mixed-scale number as a fraction, says so, and lets that admission quarantine the peak it would otherwise have called a risk.

SCALE

Why <= 1 is a question, not an assumption

  • The fixture mixes both scales: some rows are 80, some are 0.25
  • 0.25 is unambiguously a fraction; 1.0 could be 100% or 1%
  • Reading it as a fraction and flagging it is honest; picking one silently is not
  • 0 is the exception — both readings agree, so it is never flagged

ABSTENTION

The same abstention, four times

  • OVER_ALLOCATED skips any peak containing an ambiguous row
  • INACTIVE_ALLOCATED and LEAVE_COLLISION skip the row outright
  • FOLLOW_ON downgrades from a risk to a question
  • SCALE_AMBIGUOUS is the one that says out loud why the others went quiet

MATH

Why peaks, not sums

  • Summing every row in the window reads sequential work as concurrent
  • Totals can only rise at a row's start date, so those are the only dates checked
  • Each peak sums only the rows actually spanning that date
  • The result is every real maximum, and no invented one

Two detectors handle the same ambiguous row. One declines to make a claim and says nothing; the other exists solely to say why. Silence and a question are different outputs, and only one of them is honest on its own.
